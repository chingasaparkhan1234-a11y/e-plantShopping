# Paradise Nursery Shopping Application

An interactive, responsive React application built with Redux Toolkit for browsing, selecting, and purchasing indoor plants.

## Features
- **Landing Page:** Engaging welcome view featuring company background and a "Get Started" button.
- **Product Catalog:** 3 unique categories (Air Purifying, Aromatic, Low Maintenance) with 6 plants each (18 plants total).
- **Cart Management:** Redux-powered state handling for adding items, updating quantities, deleting items, and dynamically computing subtotals and total order price.
- **Responsive Layout:** Clean CSS styling designed for both desktop and mobile viewports.

## Tech Stack
- React.js
- Redux Toolkit & React-Redux
- Vite / Create React App
- CSS3
